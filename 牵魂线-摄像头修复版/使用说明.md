# 牵魂线 · 蓝雾体感版

当前为 2.1 摄像头兼容修复版。修复了本地双击 HTML 时，独立识别线程无法导入内嵌程序的问题。本地文件自动采用页面内识别；其他打开方式在独立线程失败时自动切换。手部和头部仍在本机处理，场景和手势不变。

如果你已下载旧版，请替换 HTML 和 JS 后重新打开页面；在 Live Server 中可按 Ctrl + Shift + R 强制刷新。若仍失败，新版会显示具体的失败环节与原因。

## 启动

1. 将 `index.html`、`style.css`、`script.js` 放在同一个文件夹里，文件名不要改。
2. 用 VS Code 打开这个文件夹，用 Live Server 打开 `index.html`。
3. 在 Chrome 或 Edge 中点击页面底部「开启体感」，允许使用摄像头。第一次初始化请稍等。
4. 面向摄像头坐正约两秒，完成头部基准校准。之后即可移动双手、转掌、歪头。

图片、识别程序和模型都内嵌在 `script.js` 中，因此这个文件约 28 MB，属于正常情况；不需要额外下载图片或模型，也不需要 LM Studio、Continue、API 密钥或联网服务。建议不要手动编辑文件末尾的 ASSETS 长数据。

页面只显示绘制的场景，不显示摄像头画面。摄像头图像仅在浏览器本地识别；关闭体感会释放摄像头。无摄像头时可直接进行鼠标排演。

## 手势

| 动作 | 效果 |
| --- | --- |
| 移动左手 | 布偶在画面中移动 |
| 伸直左手小拇指 | 抬起画面左侧的布偶手臂 |
| 张开左手大拇指 | 抬起画面右侧的布偶手臂 |
| 右手张开，顺时针转掌 | 布偶靠近画面 |
| 右手张开，逆时针转掌 | 布偶远离画面 |
| 右手半握，保持片刻 | 蓄起蓝色法球 |
| 右手握拳 | 法球朝屏幕飞来并爆散；一直握住不会连续发射 |
| 头部向肩膀方向倾斜 | 布偶四肢发生扭曲 |

转掌是掌心朝摄像头、在画面平面内转动，像拧方向盘；无需把掌心翻成手背。左右方向均以你看到的画面为准。布偶采用二维分段关节动画，靠近和远离通过缩放与位置变化表现。

建议让双手分开、保持在画面范围内，避免一只手挡住另一只手。半握表示四指自然弯曲但未完全握紧。如果抬错手，在「调校」中勾选左右手互换。歪头中立位置不舒服时，坐正后点击重新校准。

## 鼠标和键盘

- 移动鼠标：移动布偶。
- 按住鼠标左键或空格：蓄力；松开：投掷。
- Q / E：分别抬起画面左、右手臂。
- A / D：向两侧歪头扭曲。
- 滚轮或 [ / ]：远近。
- 方向键：移动。
- H：隐藏或恢复界面。

「玩法手记」提供操作提示；「调校」可调移动灵敏度、爆散强度和柔和模式。声音默认关闭，可用顶部按钮开启。三个小任务会保存完成进度，右侧重置按钮可以重新排演。

## 文件分工

- `index.html`：页面结构、按钮、操作手记。
- `style.css`：蓝雾界面、排版、移动端适配。
- `script.js`：动画、关节、手势、头部识别、音效、任务进度，以及内嵌素材。

JS 前半部分的 ★ 注释标出了主要课堂修改区；开头 CONFIG 集中放置蓄力时间、手势阈值、平滑速度等参数。

## 已完成的验证

在 Chrome 中验证了双臂独立抬起、远近、扭曲、蓄力投掷、持续握拳防连发、界面按钮、手机布局、摄像头关闭。使用你提供的录屏中上方的人像区域作为输入，验证了本地模型能识别双手和头部；测试中禁止了外部网络请求。未实际测试你此刻的实时摄像头，光线、遮挡和手部角度可能需要现场调校。

## 素材和组件

场景依据你提供的蓝雾操偶图重绘为独立背景与透明布偶，使用内置 image_gen 生成。眼睛保留白色眼球与红色尖角装饰。动态牵线、法球、流线、雾与爆散由 Canvas 绘制；声音由浏览器合成。背景和布偶已内嵌到 script.js。

生成要求摘要：

- 背景：保留钴蓝雾气、若隐若现的巨型操偶者和双手、更深层牵引操偶者的线、低雾和碎石地面；移除前景女孩、下垂牵线和魔法，腾出动画空间，横向绘画构图，不出现文字和摄像头画面。
- 布偶：依据已确认的女孩形象，透明背景完整全身，红棕双马尾、白色眼睛、眼部酒红尖角妆饰、微恐笑脸、蓝色层叠裙、可见关节；正面近对称姿势，双臂斜向外下方展开，四肢无遮挡，保持绘画质感。

本地识别使用 Google MediaPipe Tasks Vision 0.10.18、官方 Hand Landmarker 和 Face Landmarker 模型。Apache 2.0 许可证全文保存在 script.js 中，嵌入的程序保留原有声明。
